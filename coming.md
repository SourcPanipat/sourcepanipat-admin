# SourcePanipat Admin Command Room
- **Domain:** `admin.sourcepanipat.com`
- **Target Users:** Platform Operations & Founders.
- **Key Features:**
  - Seller management (supplier verification, ID assignment, listing toggles).
  - Order lifecycle management (Escrow hold -> QC -> Transport dispatch).
  - Inspector assignment and ₹500/task payout tracking.
  - Dispute management and logistic transit logs.
